# Watsons Exclusivity Value Survey

Commercial value survey for **Exclusive vs Non-Exclusive** renewal discussions with Key regional EB partners.

## Features
- **Buyer Code Tracking**: Required `Buyer Code` field to distinguish ~20 respondents.
- **Exact Benchmark Structure**: Covers all 6 Key Measures (Store distribution, Space allocation, Annual growth target, Listing fee, Marketing Support, Business reviews) plus additional suggested measures.
- **Auto-Calculations**: Automatically computes `+ stores`, `+ %`, `+ pt`, and `+ reviews` in the Exclusivity Value column.
- **Export & Consolidate**:
  - Export individual or all collected responses as **Excel-ready CSV (UTF-8 BOM)** or **JSON**.
  - **Batch Import & Merge**: Drag and drop multiple buyers' `.csv` or `.json` files to merge and deduplicate by `Buyer Code` into one master CSV.
  - **Optional Google Sheets Sync**: Supports posting directly to a Google Apps Script Web App URL.
